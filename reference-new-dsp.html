New DSP

"New DSP" refers to the current pipeline used in Scanline Classic. It incorporates lessons learned from previous pipelines and aims to provide a more comprehensive and reliable simulation of classic display characteristics by defining strict DSP domains using contract-based design. The pipeline is divided into four primary domains: the Pixel Clock domain, the DSP domain, the Physical domain, and the Output domain.
